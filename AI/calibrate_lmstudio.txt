******************************************************
1. Inference parameters (temperature, top_p, etc.)
******************************************************
Temperature (creativity vs accuracy)
Range: 0 → 1+
Controls randomness

temperature = 0.2   # precise, deterministic
temperature = 0.7   # balanced (default-ish)
temperature = 1.0+  # creative, risky

How to think about it:
Coding / factual answers → 0.1–0.3
General chat → 0.5–0.8
Creative writing → 0.9–1.2

If your model is hallucinating → lower temperature first
--------------------------------------
Top_p (nucleus sampling)
Range: 0 → 1
Controls how much of the probability distribution is used

top_p = 0.9   # common default
top_p = 0.5   # more focused

Rule of thumb:
Lower = safer, more repetitive
Higher = more diverse

👉 Don’t aggressively tune both temperature AND top_p at the same time — pick one as your main control.
--------------------------------------
Top_k (token filtering)
Limits number of candidate tokens

top_k = 40   # common
top_k = 10   # very strict
👉 Lower = more deterministic
👉 Higher = more variety
--------------------------------------
Repeat penalty (VERY important)
Prevents loops and repetition.
repeat_penalty = 1.1–1.3

Too low → model repeats itself
Too high → weird phrasing

👉 If you see:

“Yes yes yes yes yes…”

Increase this.
--------------------------------------
Max tokens (output length)
max_tokens = 200

Controls response length.

👉 If responses are cut off → increase this
👉 If too verbose → lower it
