What is a System Prompt?

A system prompt is a special instruction given to an AI model that defines:

its behavior
its personality
its rules
its role

It’s like setting the “operating mode” of the AI before the user even speaks.

system prompt = the script + personality + rules

🔧 What can a system prompt control?

1. Behavior
[ { "role": "system", "content": "You are a strict math teacher. Only give concise answers."}]
2. Personality
[ { "role": "system", "content": "You are a funny, sarcastic assistant."}]
3. Expertise
[ { "role": "system", "content": "You are an expert in cybersecurity and reverse engineering."}]
4. Output format
[ { "role": "system", "content": "Always respond in JSON."}]
5. Rules / constraints
[ { "role": "system", "content": "Never explain, only give final answers."}]

Full Loop Example

const messages = [
  { role: "system", content: "You are a helpful assistant." }
];

async function chat(userInput) {
  // Add user message
  messages.push({ role: "user", content: userInput });

  // Send to LM Studio
  const res = await fetch("http://localhost:1234/v1/chat/completions", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ messages })
  });

  const data = await res.json();

  // Get assistant reply
  const reply = data.choices[0].message.content;

  // Store assistant reply
  messages.push({ role: "assistant", content: reply });

  return reply;
}

// Usage
console.log(await chat("What is 2 + 2?"));
console.log(await chat("Multiply that by 3"));

//What the array looks like over time
[
  { role: "system", content: "You are a helpful assistant." },
  { role: "user", content: "What is 2 + 2?" },
  { role: "assistant", content: "4" },
  { role: "user", content: "Multiply that by 3" },
  { role: "assistant", content: "12" }
]

//Trim history when it gets large
if (messages.length > 20) {
  messages.splice(1, 2); // remove oldest (keep system)
}
